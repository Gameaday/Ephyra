## Status vocabulary

- `NOT_STARTED`: no implementation accepted.
- `IN_PROGRESS`: work exists but no phase gate is satisfied.
- `CODE_COMPLETE`: implementation and automated tests pass.
- `DEVICE_VERIFIED`: verified on declared physical/emulator matrix.
- `BLOCKED`: cannot proceed; blocker and owner are recorded.
- `ACCEPTED_DEBT`: consciously deferred with expiry/review condition.
- `VERIFIED`: all phase exit criteria satisfied.

## Evidence levels

Levels are defined by **what produces the evidence**, so a row is never expected to reach a level
this programme has no means to produce. See [`adr/0009`](adr/0009-evidence-channels-match-validation.md).

| Level | Evidence | Produced by |
|---|---|---|
| `E0` | claim only; no executable evidence |  |
| `E1` | static inspection | a reader |
| `E2` | JVM/Robolectric unit test | CI |
| `E3` | instrumentation, screenshot, or pointer-event test on an emulator | CI or a local emulator run |
| `E4-user` | validation on real user devices from a pushed build | the release/validation process |
| `E4-lab` | physical or representative device evidence produced in-tree | a deliberately set-up lab device |
| `E5` | macrobenchmark / performance measurement | a benchmark run |

A task may be `CODE_COMPLETE` at `E2`. `DEVICE_VERIFIED` requires `E3` **plus** one of `E4-user` /
`E4-lab`, and each row declares which one it is waiting on.

Three rules follow, and they exist because their absence caused a fabricated evidence pass on
2026-09-25:

1. **A missing channel is a blocker, not a pass.** If a row needs a channel that does not exist, it is
   `BLOCKED` naming the channel. Never `pass`.
2. **An evidence record may only describe a run that occurred.** It names the build or commit, the
   device or device class, the exact steps, and the observed result. A record whose reproduction
   cannot be re-performed is void regardless of outcome.
3. **A claim that could regress silently again is gated at `E3`, not `E4-user`.** `E4-user` confirms
   behaviour; only a repeatable in-repository test guards it.
